그룹화와 캡처 - 패턴의 일부 추출하기

Part 2 · 정규표현식 - 문자열 패턴 매칭의 기술

🚀 이 장을 시작하기 전에

섹션 제목: “🚀 이 장을 시작하기 전에”

이메일 hong@gmail.com에서 아이디 hong만 뽑고 싶을 때, 지금까지 배운 패턴으로는 전체 이메일을 찾을 수는 있어도 일부분만 꺼내기가 어려웠어요. 바로 이때 쓰는 게 그룹화 ( ) 입니다. 괄호로 원하는 부분을 묶어두면, 정규표현식이 그 부분만 골라서 돌려줘요. AI/데이터 분석 실무에서 로그 파싱, 정보 추출에 매일 쓰이는 핵심 기술이에요.

🎯 이 장의 학습 목표

섹션 제목: “🎯 이 장의 학습 목표”

이 장을 마치면 여러분은:

  • ✅ ( )를 사용해 그룹을 만들 수 있어요
  • ✅ group(), groups()로 캡처된 내용을 추출할 수 있어요
  • ✅ | 연산자로 여러 패턴 중 하나를 매칭할 수 있어요

⏰ 예상 학습 시간: 약 10분

🔑 미리 확인해요

섹션 제목: “🔑 미리 확인해요”

이전 장에서 배운 re.search()와 match 객체를 기억하나요? 빠르게 확인해봐요.

match.group()이 매칭된 전체 문자열을 돌려준다는 것, 기억하셨으면 바로 출발해요! 💪

📚 핵심 개념

섹션 제목: “📚 핵심 개념”

개념 1: 그룹 ( ) — 원하는 부분에 형광펜 긋기

섹션 제목: “개념 1: 그룹 ( ) — 원하는 부분에 형광펜 긋기”

비유: 긴 문장에서 형광펜으로 특정 단어에 밑줄을 긋는 것처럼, ( )는 패턴의 일부에 “이 부분만 따로 챙겨줘”라고 표시하는 역할이에요.

정확한 정의: 정규표현식에서 ( )로 감싼 부분을 캡처 그룹이라고 해요. 매칭이 성공하면 그 부분이 별도로 저장되어, 나중에 group(번호)로 꺼낼 수 있어요.

2번째 줄 (\w+)가 바로 캡처 그룹입니다. group(0)은 전체, group(1)은 첫 번째 ( ) 안의 내용이에요.

개념 2: groups() — 여러 그룹 한 번에 꺼내기

섹션 제목: “개념 2: groups() — 여러 그룹 한 번에 꺼내기”

그룹이 여러 개면 groups()가 모든 그룹을 튜플로 돌려줘요.

메서드반환값언제 쓰나요?
group(0) 또는 group()전체 매칭 문자열매칭 전체가 필요할 때
group(1), group(2) …N번째 그룹특정 하나만 꺼낼 때
groups()모든 그룹의 튜플여러 그룹을 한꺼번에 처리할 때

🔍 체크포인트: group(1)과 groups()의 차이를 한 문장으로 설명할 수 있나요? 할 수 있다면 다음으로! 💪

개념 3: | 연산자 — “이것 또는 저것”

섹션 제목: “개념 3: | 연산자 — “이것 또는 저것””

|는 OR 역할이에요. 고양이|강아지는 “고양이 또는 강아지”를 매칭해요.

( )와 |를 함께 쓰면 더 강력해져요.

🔍 체크포인트: cat|dog와 (cat|dog)s의 차이가 느껴지나요? 후자는 cats 또는 dogs를 매칭해요. 이해됐으면 실습으로 가요!

실습: 로그에서 날짜와 오류 코드 추출하기

섹션 제목: “실습: 로그에서 날짜와 오류 코드 추출하기”

실제 서버 로그처럼 생긴 문자열에서 날짜와 오류 레벨을 뽑아내는 실습이에요.

따라하기:

1단계 — 아래 코드를 그대로 복사해서 실행해보세요.

✅ 확인: 연도·월·일이 따로따로 출력되면 성공이에요! ❓ AttributeError: 'NoneType' 에러가 나요? → log 변수 안에 날짜 형식이 정확히 있는지 확인하세요. 오타가 없는지도요.

2단계 — 날짜 + 오류 레벨을 함께 추출해봐요.

✅ 확인: 날짜와 레벨이 각각 깔끔하게 출력되면 완성이에요!

🎉 훌륭해요! 실무 로그 파서를 직접 만들어봤어요!

❓ 자주 묻는 질문 & 막혔을 때

섹션 제목: “❓ 자주 묻는 질문 & 막혔을 때”
Q. group(1)인데 왜 IndexError가 나요?

re.search()가 None을 반환했거나, 패턴에 ( )가 없을 때 발생해요. 두 가지를 확인하세요.

  1. match가 None인지 먼저 체크: if match: 조건문을 앞에 붙이세요.
  2. 패턴에 ( )가 있는지 확인: r'\d+'는 그룹 없음, r'(\d+)'는 그룹 1번 있음.
Q. groups()가 튜플인데, 값을 따로 꺼내려면요?

두 가지 방법이 있어요.

그룹 수와 변수 수가 맞아야 해요. 그룹이 3개면 변수도 3개!

Q. |를 쓸 때 cat|cats를 하면 항상 cat만 매칭돼요. 왜요?

정규표현식은 왼쪽부터 먼저 시도해요. cat이 먼저 매칭되면 거기서 멈춰요. cats|cat 순서로 바꾸면 해결돼요. 긴 패턴을 먼저 쓰는 것이 원칙이에요.
