상속과 메서드 오버라이딩 - 클래스 확장하기

🚀 이 장을 시작하기 전에

섹션 제목: “🚀 이 장을 시작하기 전에”

AI 모델을 만들다 보면 “기본 모델”과 “개선된 모델”이 코드의 90%를 공유하는 경우가 많아요. 상속을 쓰면 공통 코드를 한 번만 쓰고, 달라지는 부분만 덮어쓸 수 있습니다. 복붙 없이 깔끔하게요.

🎯 이 장의 학습 목표

섹션 제목: “🎯 이 장의 학습 목표”

이 장을 마치면 여러분은:

  • ✅ 상속 문법(class 자식(부모))을 작성할 수 있습니다
  • ✅ 부모 메서드를 오버라이딩할 수 있습니다
  • ✅ super()로 부모 기능을 재사용할 수 있습니다

⏰ 예상 학습 시간: 약 10분

🔑 미리 확인해요

섹션 제목: “🔑 미리 확인해요”

📚 핵심 개념

섹션 제목: “📚 핵심 개념”

개념 1: 상속 — “부모껄 그대로 물려받기”

섹션 제목: “개념 1: 상속 — “부모껄 그대로 물려받기””

스마트폰을 생각해 보세요. 갤럭시 S24는 기본 스마트폰의 모든 기능(전화, 문자)을 갖추면서, 새로운 카메라 기능을 추가한 거잖아요. 이게 상속입니다.

문법: class 자식클래스(부모클래스):

class Dog(Animal) — 2번째 줄의 괄호 안 Animal이 바로 부모 클래스 지정입니다. Dog는 Animal의 모든 메서드를 자동으로 물려받아요.

🔍 체크포인트: Dog 클래스 안에 speak()를 따로 쓰지 않았는데 왜 실행될까요? “부모한테 물려받았으니까!” — 이걸 한 문장으로 말할 수 있으면 다음으로 GO! 💪

개념 2: 메서드 오버라이딩 — “내 방식대로 바꾸기”

섹션 제목: “개념 2: 메서드 오버라이딩 — “내 방식대로 바꾸기””

물려받은 기능이 마음에 안 들면 같은 이름의 메서드를 자식 클래스에 다시 정의하면 됩니다. 이걸 오버라이딩(overriding)이라고 해요.

핵심은 메서드 이름이 같아야 한다는 것이에요. 이름이 같으면 자식 것이 우선합니다.

개념 3: super() — “부모 기능도 쓰고 싶을 때”

섹션 제목: “개념 3: super() — “부모 기능도 쓰고 싶을 때””

오버라이딩하면 부모 메서드가 완전히 사라질까요? 아니에요. super()를 쓰면 부모 메서드를 그대로 호출하고 거기에 기능을 추가할 수 있어요.

super().__init__(name) — 4번째 줄이 바로 부모 생성자 호출입니다. 부모가 self.name을 세팅하게 한 뒤, 자식은 self.breed만 추가하면 돼요. 코드 중복 없이!

🔍 체크포인트: super()가 없으면 어떻게 될까요? 잠깐 생각해 보세요. 바로 다음에 에러 실험으로 확인해 봅니다! 💪

⚠️ 에러 실험: super() 빼면 어떻게 될까요?

섹션 제목: “⚠️ 에러 실험: super() 빼면 어떻게 될까요?”

이 코드를 실행해 보세요.

원인: super().__init__(name)을 빼면 부모의 __init__이 실행되지 않아요. 그래서 self.name이 만들어지지 않습니다.

수정: super().__init__(name) 주석을 해제하면 해결돼요.

❓ 자주 묻는 질문 & 막혔을 때

섹션 제목: “❓ 자주 묻는 질문 & 막혔을 때”
Q. 오버라이딩할 때 메서드 이름을 다르게 쓰면 안 되나요?

다르게 쓰면 오버라이딩이 아니라 새 메서드 추가가 됩니다. 부모의 speak()를 바꾸고 싶으면 자식에도 반드시 speak()라는 이름을 써야 해요. 이름이 달라지면 부모 것과 자식 것이 둘 다 존재하게 됩니다.

Q. super()를 항상 써야 하나요?

아니에요. 부모의 기능이 전혀 필요 없고 완전히 새로 짜고 싶을 때는 super() 없이 오버라이딩하면 됩니다. 단, __init__에서는 부모 속성이 필요한 경우가 많아서 습관적으로 super().__init__()을 쓰는 게 안전해요.

Q. 상속을 여러 번 할 수 있나요?

네! Animal → Dog → GuideDog 처럼 여러 단계로 이어질 수 있어요. 이걸 다단계 상속이라고 합니다. 메서드를 찾을 때는 자식 → 부모 → 조부모 순서로 올라가며 찾습니다. 이건 다음 심화 단계에서 더 자세히 다뤄요.

🧩 연습 문제

섹션 제목: “🧩 연습 문제”
⭐ 기초: Vehicle과 Car

Vehicle 클래스에 move() 메서드가 있어요. Car 클래스가 이를 상속받아 move()를 오버라이딩해서 "부릉부릉!" 을 출력하게 만들어 보세요.

힌트: class Car(Vehicle): 로 시작하고, 안에 def move(self): 를 작성하면 됩니다.

⭐⭐ 응용: 정확도가 다른 두 AI 모델

BaseModel(model_name, accuracy) 을 부모로 만들고, FastModel과 AccurateModel 두 자식 클래스를 만드세요. 각각 predict() 오버라이딩 시 "빠른 예측:", "정밀 예측:" 접두어를 붙여 출력하세요.

힌트: 두 자식 클래스 모두 super().__init__(model_name, accuracy) 로 시작해요.

⭐⭐⭐ 도전: 로그 기능 추가

BaseModel의 predict()를 오버라이딩하되, super().predict()도 실행하고 추가로 호출 횟수를 세는 call_count 속성을 만들어 보세요.

힌트: __init__에서 self.call_count = 0 초기화, predict() 안에서 self.call_count += 1.
