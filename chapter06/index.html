특수 메서드와 종합 실습 - 클래스 완성하기

🚀 이 장을 시작하기 전에

섹션 제목: “🚀 이 장을 시작하기 전에”

print(내_객체)를 했을 때 <__main__.Dog object at 0x...> 같은 이상한 글자가 나온 적 있죠? 특수 메서드를 쓰면 진돗개 바둑이 (3살)처럼 원하는 형태로 출력할 수 있어요. 지금까지 배운 클래스 지식을 모두 합쳐 “완성된 클래스”를 만들어 봅시다!

🎯 이 장의 학습 목표

섹션 제목: “🎯 이 장의 학습 목표”

이 장을 마치면 여러분은:

  • ✅ __str__, __eq__, __len__ 특수 메서드를 정의할 수 있습니다
  • ✅ 생성자, 메서드, 특수 메서드를 결합한 완성된 클래스를 작성할 수 있습니다

⏰ 예상 학습 시간: 약 7분

🔑 미리 확인해요

섹션 제목: “🔑 미리 확인해요”

지난 장에서 배운 __init__도 특수 메서드입니다. 앞뒤로 언더바 두 개(__)가 붙은 메서드는 Python이 특별한 상황에서 자동으로 호출해요. 오늘은 그 종류를 3개 더 배웁니다.

📚 핵심 개념: 특수 메서드 (Magic Method)

섹션 제목: “📚 핵심 개념: 특수 메서드 (Magic Method)”

Python은 특정 상황이 되면 자동으로 정해진 이름의 메서드를 호출합니다.

상황자동 호출되는 메서드예시
print(객체) 또는 str(객체)__str__print(dog)
객체1 == 객체2__eq__dog1 == dog2
len(객체)__len__len(team)

쉽게 말하면: __str__은 “내 이름표”이고, __eq__는 “나랑 저쪽이 같은지 판단하는 기준”이에요.

🔍 체크포인트: print(obj) 를 실행할 때 Python이 자동 호출하는 메서드 이름은 무엇인가요? 기억난다면 다음으로! 💪

실습: AI 모델 카드 클래스 만들기

섹션 제목: “실습: AI 모델 카드 클래스 만들기”

AI/머신러닝 현장에서는 모델 정보를 한 객체로 묶어 관리해요. 같이 만들어 봅시다.

v1 — 기본 클래스 (print하면 이상한 주소 출력)

이 출력은 아무 정보도 담고 있지 않아요. __str__을 추가해 봅시다.

v2 — __str__ 추가 (print가 예쁘게 나옴)

3번째 줄 def __str__(self)이 바로 특수 메서드입니다. 직접 model.__str__()을 호출하지 않아도 print(model) 만으로 실행돼요.

✅ 확인: ResNet | 정확도: 92.0% 가 출력되어야 해요. ❓ 안 되나요? → def __str__(self): 의 언더바 개수가 앞뒤 각 2개인지 확인하세요.

v3 — __eq__와 __len__ 추가 (비교와 길이)

✅ 확인: True, False, 6 이 순서대로 출력되어야 해요.

🎉 특수 메서드 3개를 모두 장착했어요!

❓ 자주 묻는 질문 & 막혔을 때

섹션 제목: “❓ 자주 묻는 질문 & 막혔을 때”
Q. __str__ 대신 그냥 show() 메서드를 만들면 안 되나요?

가능해요! 하지만 __str__을 정의하면 print(), str(), f-string 안에 넣을 때 모두 자동으로 예쁜 출력이 나와요. show()는 직접 model.show()를 호출해야 하죠. 표준 방법을 따르면 다른 사람 코드와도 잘 어울립니다.

Q. __eq__ 안 쓰면 == 은 어떻게 동작하나요?

정의하지 않으면 Python은 기본적으로 메모리 주소가 같은지 비교해요. 즉, 내용이 똑같아도 다른 변수에 담긴 객체라면 False가 나옵니다.
