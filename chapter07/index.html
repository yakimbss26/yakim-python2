왜 정규표현식인가 - 문자열 처리의 강력한 도구

Part 2. 정규표현식 - 문자열 패턴 매칭의 기술

🚀 이 장을 시작하기 전에

섹션 제목: “🚀 이 장을 시작하기 전에”

사용자가 입력한 이메일 주소가 올바른 형식인지 확인해야 한다고 상상해 보세요. @가 있는지, .com으로 끝나는지 일일이 if문으로 체크한다면 코드가 10줄이 넘어갑니다. 정규표현식을 쓰면 딱 한 줄로 해결됩니다. AI 모델에 넣을 데이터를 정제할 때도, 텍스트에서 특정 패턴을 뽑아낼 때도 정규표현식은 필수 도구입니다.

🎯 이 장의 학습 목표

섹션 제목: “🎯 이 장의 학습 목표”

이 장을 마치면 여러분은:

  • ✅ 정규표현식이 어떤 문제를 해결하는지 설명할 수 있습니다
  • ✅ re 모듈을 import하고 search, findall을 호출할 수 있습니다
  • ✅ 단순 문자 패턴으로 텍스트를 검색할 수 있습니다

⏰ 예상 학습 시간: 약 8분

🔑 미리 확인해요

섹션 제목: “🔑 미리 확인해요”

문자열 메서드 in과 find()를 기억하시나요?

이 방법으로는 정확히 일치하는 문자열만 찾을 수 있습니다. “숫자로 된 전화번호”, “이메일 형식” 같은 패턴은 찾지 못해요. 이게 정규표현식이 필요한 이유입니다.

📚 핵심 개념

섹션 제목: “📚 핵심 개념”

개념: 정규표현식은 “패턴 도장”이다

섹션 제목: “개념: 정규표현식은 “패턴 도장”이다”

비유로 시작: 도장을 생각해 보세요. “전화번호 모양 도장”을 텍스트 위에 쭉 밀면, 도장 모양과 일치하는 부분만 찍힙니다. 정규표현식(Regular Expression, 줄여서 regex)은 바로 그 도장의 모양을 글자로 표현한 것입니다.

정확한 설명: 정규표현식은 문자열의 패턴을 기술하는 특수 문법입니다. Python에서는 re 모듈이 이 도장을 다루는 도구 상자 역할을 합니다.

세 가지 핵심 함수를 비교하면 이렇습니다:

함수하는 일언제 쓰나
re.search()텍스트 어디서든 패턴 첫 번째 발견”있냐 없냐”만 확인할 때
re.match()텍스트 시작 부분에서만 패턴 확인입력값 형식 검증할 때
re.findall()패턴과 일치하는 모든 결과를 리스트로 반환여러 개 전부 뽑아낼 때

🔍 체크포인트: “전체 텍스트에서 전화번호를 모두 뽑고 싶다” → 어떤 함수를 써야 할까요? findall이라고 떠올랐다면 완벽해요! 💪

🔧 직접 해봐요

섹션 제목: “🔧 직접 해봐요”

실습: 텍스트에서 패턴 찾기

섹션 제목: “실습: 텍스트에서 패턴 찾기”

따라하기 — Step 1: re 모듈 불러오기

먼저 가장 기본적인 형태로 시작합니다.

None이 아닌 Match 객체가 나왔으면 성공입니다! span=(7, 8)은 7번째 인덱스에서 발견했다는 뜻이에요.

✅ 확인: 출력에 match='3'이 보여야 해요. ❓ None이 나왔나요? → text 변수에 “3”이 있는지 다시 확인해 보세요.

따라하기 — Step 2: findall로 여러 개 한 번에 뽑기

이제 실전처럼 여러 숫자가 섞인 텍스트에서 전부 뽑아봅시다.

텍스트 안의 모든 숫자가 리스트로 쏙 뽑혔어요! 🎉

✅ 확인: ['1', '72', '2', '85', '3', '91']이 출력되어야 해요.

위 코드 2번째 줄의 "\d+"가 바로 패턴(도장 모양)입니다. \d는 숫자, +는 “한 개 이상”을 의미해요. 이 기호들은 다음 챕터에서 본격적으로 배웁니다. 지금은 “패턴을 문자열로 쓴다”는 흐름만 잡아 두세요.

잠깐! 이런 실수 조심해요 🚨

re를 import하지 않으면 어떻게 될까요?

원인: re는 Python 내장 모듈이지만, 사용 전에 반드시 import re를 선언해야 합니다. 수정: 첫 줄에 import re를 추가하면 즉시 해결돼요.

❓ 자주 묻는 질문

섹션 제목: “❓ 자주 묻는 질문”
Q. search와 match의 차이가 아직 헷갈려요

간단한 실험으로 확인해 보세요!

match는 텍스트의 첫 글자부터 패턴이 맞아야 성공합니다. 대부분의 경우 search가 더 편리해요.

Q. findall 결과가 왜 숫자인데 문자열 리스트로 나오나요?

re.findall()은 항상 문자열 리스트를 반환합니다. 숫자 계산에 쓰려면 int()로 변환하면 돼요.

📌 이 장에서 배운 것 정리

섹션 제목: “📌 이 장에서 배운 것 정리”

🏆 오늘의 성취: 정규표현식의 필요성을 이해하고, re 모듈로 텍스트 패턴을 검색할 수 있어요!

  • ✅ 정규표현식은 문자열 패턴을 기술하는 도구다
  • ✅ re.search(): 하나 찾기 / re.findall(): 전부 찾기
  • ✅ import re를 빠뜨리면 NameError가 발생한다
