종합 실전 문제 - 정규표현식 마스터하기

🚀 이 장을 시작하기 전에

섹션 제목: “🚀 이 장을 시작하기 전에”

지금까지 배운 모든 도구를 꺼내 쓸 시간이에요! 이메일 주소, 전화번호, 날짜 형식은 실무와 시험 모두에서 가장 자주 나오는 패턴입니다. 이 장을 마치면 “정규표현식 문제라면 자신 있다!”고 말할 수 있어요.

🎯 학습 목표

섹션 제목: “🎯 학습 목표”
  • ✅ 이메일, 전화번호 패턴을 직접 설계할 수 있습니다
  • ✅ 지금까지 배운 메타문자, 수량자, 그룹을 결합할 수 있습니다

⏰ 예상 학습 시간: 약 5분

🔑 미리 확인해요

섹션 제목: “🔑 미리 확인해요”
기호의미
\d숫자
+, *, ?수량자 (1회 이상, 0회 이상, 0-1회)
()그룹 묶기
[]문자 클래스

📚 핵심 개념: 실전 패턴 설계 전략

섹션 제목: “📚 핵심 개념: 실전 패턴 설계 전략”

복잡한 패턴도 “덩어리로 쪼개기” 전략이면 쉬워요. 이메일을 예로 들면:

user@example.com → 사용자명 + @ + 도메인 + . + 최상위도메인 3개 덩어리로 분리합니다.

🔍 체크포인트: 패턴을 만들기 전, 먼저 “이 문자열은 어떤 덩어리로 이루어졌나?” 질문을 던질 수 있나요? 그렇다면 다음으로! 💪

🔧 직접 해봐요

섹션 제목: “🔧 직접 해봐요”

실습 1: 이메일 패턴 만들기

섹션 제목: “실습 1: 이메일 패턴 만들기”

따라하기:

v1 — 덩어리를 코드로 옮기기

✅ 확인: 3줄의 결과가 위와 같이 나와야 해요! ❓ {2,} 가 생소하다면? “2개 이상”을 뜻하는 수량자입니다. {2,5}는 2-5개.

실습 2: 전화번호 패턴 + 치환

섹션 제목: “실습 2: 전화번호 패턴 + 치환”

v2 — 패턴 추출 후 형식 통일

6번째 줄 [\s-]?가 핵심입니다. “공백이나 하이픈이 있어도 되고 없어도 된다”는 유연성이에요.

🔍 체크포인트: 01[016789]가 왜 이렇게 생겼는지 설명할 수 있나요? (010, 011, 016, 017, 018, 019를 허용하기 위해서입니다) 💪

❓ 자주 묻는 질문

섹션 제목: “❓ 자주 묻는 질문”
Q. \w 와 [a-zA-Z0-9_] 는 같은 건가요?

네, 완전히 같습니다! \w는 [a-zA-Z0-9_]의 줄임말이에요. 한 글자라도 줄이는 게 실무 관행입니다.

Q. re.search와 re.fullmatch 중 언제 뭘 쓰나요?

search는 문자열 일부만 매칭되어도 OK, fullmatch는 문자열 전체가 패턴과 일치해야 합니다. 유효성 검사(이메일이 올바른 형식인지)에는 fullmatch를 쓰세요.

📌 이 장에서 배운 것 정리

섹션 제목: “📌 이 장에서 배운 것 정리”

🏆 오늘의 성취: 이제 이메일, 전화번호 같은 실전 패턴을 설계하고 검증할 수 있어요!

  • ✅ 복잡한 패턴은 “덩어리로 쪼개기” 전략으로 접근
  • ✅ [\s-]? 같은 유연한 수량자로 다양한 입력 형식을 처리
  • ✅ re.search, re.fullmatch를 상황에 맞게 선택

🤔 스스로 점검해봐요

섹션 제목: “🤔 스스로 점검해봐요”
  • 이메일 패턴의 3개 덩어리를 설명할 수 있나요?
  • {2,}, [\s-]? 의 의미를 말할 수 있나요?
  • 새로운 패턴을 설계할 때 “덩어리 쪼개기”를 떠올릴 수 있나요?

💡 어렵다면? 실습 1의 주석을 다시 읽고, 직접 패턴을 손으로 써보세요. 괜찮아요!
