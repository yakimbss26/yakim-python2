섹션 제목: “🚀 이 장을 시작하기 전에”

📚 핵심 개념: 메서드와 self

섹션 제목: “📚 핵심 개념: 메서드와 self”

메서드 = 클래스 안에 정의된 함수

섹션 제목: “메서드 = 클래스 안에 정의된 함수”

비유: 스마트폰에는 버튼(속성)도 있지만, “전화 걸기”, “사진 찍기” 같은 기능(메서드)도 있어요. 메서드는 그 기능입니다.

정확한 정의: 메서드는 class 블록 안에 def로 정의한 함수예요. 일반 함수와 딱 하나가 달라요 — 첫 번째 매개변수가 항상 self입니다.

self가 뭔가요? 메서드를 호출할 때 Python이 자동으로 “이 메서드를 호출한 인스턴스”를 첫 번째 자리에 넣어줘요. 즉, hero.greet()를 실행하면 Python 내부에서 Hero.greet(hero)처럼 동작해요. self는 “나 자신”입니다.

🔍 체크포인트: self를 빼고 메서드를 정의하면 어떻게 될까요? 잠깐 생각해보세요. 바로 아래에서 확인할 거예요! 💪

섹션 제목: “실습 1: 메서드 추가하기 (v1 → v2)”

v1 — 메서드 하나 추가

Python 3.11 환경에서 새 파일을 만들고 아래 코드를 그대로 입력해 보세요.

✅ 확인: 나는 아린, HP: 100이 출력되어야 해요. ❓ 안 되나요? → 들여쓰기가 맞는지 확인하세요. def greet는 class 아래에 스페이스 4칸 들여쓰기가 필요해요.

⚠️ 에러 경험해보기 — self를 빼면?

이 코드를 실행하면 어떤 에러가 날까요?

원인: hero.greet()를 실행하면 Python이 hero 자신을 첫 번째 인자로 자동 전달해요. 그런데 greet()에는 받을 매개변수가 없으니 “인자를 1개 줬는데 받는 자리가 없다”는 에러가 나요.

수정: def greet(self):로 self를 첫 번째 매개변수로 추가하면 해결돼요. ✅

v2 — 속성을 변경하는 메서드

이제 행동을 하면 속성이 바뀌게 만들어 볼게요.

코드 매핑:

  • 9번째 줄 self.hp += amount — 이것이 핵심이에요. self를 통해 자기 자신의 속성을 메서드 안에서 수정하는 부분입니다.
  • 6번째 줄 def attack(self, damage) — self 다음에 일반 매개변수를 얼마든지 추가할 수 있어요.

❓ 자주 묻는 질문 & 막혔을 때

섹션 제목: “❓ 자주 묻는 질문 & 막혔을 때”
Q. 메서드를 호출할 때 왜 self를 안 써도 되나요?

hero.greet()처럼 점(.)을 이용해 호출하면, Python이 자동으로 점 앞의 객체(hero)를 self 자리에 넣어줘요. 우리가 직접 쓸 필요가 없는 거예요. 반대로 메서드를 정의할 때는 반드시 받아야 하니까 def greet(self):로 써줘야 해요.

Q. self 말고 다른 이름을 써도 되나요?

기술적으로는 def greet(this): 처럼 다른 이름도 돼요. 하지만 파이썬 개발자 전체가 self를 쓰는 것이 강력한 관례예요. self가 아닌 이름을 쓰면 코드를 읽는 사람이 혼란스러워하니까, 항상 self를 쓰세요.

Q. 함수와 메서드는 뭐가 다른가요?
구분함수메서드
위치클래스 밖에 정의클래스 안에 정의
첫 번째 매개변수없어도 됨반드시 self
호출 방법greet()hero.greet()
